# 🎧 Listening Practice Web App
Aplikasi web interaktif untuk latihan *listening* lewat lirik lagu. 
Ubah video YouTube jadi soal rumpang otomatis.

🔗 **Live Demo:** [https://misteralku.github.io/listening/](https://misteralku.github.io/listening/)

---

## ✨ Fitur Utama
**🎬 Sumber Lirik Otomatis**
- Ambil lirik dari link YouTube
- Fallback otomatis ke LRCLIB (synced & plain)
- Support paste manual format LRC

**🧩 Mode Latihan Cerdas**
- 2 tipe: tebak kata hilang & tebak kalimat
- 5 level kesulitan (1-5)
- Distraktor pakai phonetic, homophone & grammar

**🎧 Player Sinkron**
- Lirik highlight ngikutin video
- Klik lirik untuk seek video
- Chorus detection

**📱 UX**
- Responsive
- Score & akurasi live
- Follow lyrics mode

## 🎯 Cara Pakai
1. Buka [Live Demo](https://misteralku.github.io/listening/)
2. Paste link YouTube lagu favoritmu
3. Pilih tipe latihan & level kesulitan
4. Klik **Generate** dan jawab soal rumpang
5. Lihat skor & akurasi di akhir sesi
